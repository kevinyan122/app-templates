# Vendored CH-Bench data

The `contextheavy` directory is copied from
[`shihabshahrier/CH-Bench`](https://github.com/shihabshahrier/CH-Bench) at commit
`5a08786a9b74896a139183a7ee8b8a4e066c9428`.

It contains the five profession tracks used by the ContextHeavy-Bench suite: 44 memories and 35
questions. The upstream project declares the dataset and harness under the MIT license. Keep the
source commit pinned so evaluation runs remain reproducible; review upstream changes deliberately
before refreshing these files.
